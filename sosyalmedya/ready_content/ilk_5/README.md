# İlk 5 Hazır İçerik Çıktıları

Bu klasör `sosyalmedya/create_first_5_assets.py` ile üretildi.

## İçerikler

- `01_reels_lansman/`
  - Reels/TikTok lansman kapak görseli ve storyboard kareleri.
  - Format: 1080x1920.

- `02_carousel_3_adim/`
  - Instagram carousel için 5 slayt.
  - Format: 1080x1080.

- `03_story_anket/`
  - Instagram story anket serisi için 4 story görseli.
  - Format: 1080x1920.

- `04_reels_30_saniye/`
  - "30 saniyede rapor nasıl atılır?" Reels/TikTok kapak ve storyboard kareleri.
  - Format: 1080x1920.

- `05_x_paylasim/`
  - X paylaşımı için yatay görsel kart.
  - Format: 1600x900.

## Kullanım

Metin, caption ve hashtagler için:

`sosyalmedya/hazir_icerikler_ilk_5.md`

Görselleri yeniden üretmek için:

```bash
python sosyalmedya/create_first_5_assets.py
```
